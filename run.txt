3) Bấm "Load unpacked / Tải tiện ích đã giải nén" -> chọn thư mục:

4) Bấm biểu tượng T12 Studio trên thanh tiện ích -> "Mở tool".
Mỗi khi mã extension thay đổi: bấm nút tải lại (Reload) của T12 Studio trong chrome://extensions.

9. ĐỒNG BỘ DATABASE QUA GIT (tài khoản, mật khẩu, tác vụ, lịch sử)
-------------------------------------------------------------------
File backend\data\studio.sqlite3 được đưa lên GitHub (repo đang công khai).
Database là file nhị phân, Git không gộp được khi 2 máy cùng sửa -> mỗi lúc chỉ làm việc trên 1 máy.

Máy vừa làm việc xong (đẩy lên):
    (dừng backend bằng Ctrl+C trước)
    git add backend\data\studio.sqlite3
    git commit -m "Cap nhat database"
    git push

Máy kia (lấy về):
    (dừng backend bằng Ctrl+C trước)
    git pull
    .\start-backend.cmd

Lần đầu kéo database về một máy đã tự tạo database riêng, git báo
"untracked working tree files would be overwritten" -> đổi tên file cũ rồi pull lại:
    ren backend\data\studio.sqlite3 studio.old.sqlite3
    git pull

Nếu 2 máy cùng sửa và git báo conflict ở studio.sqlite3 -> chọn giữ 1 bản:
    git checkout --theirs backend\data\studio.sqlite3   (lấy bản trên GitHub)
    hoặc
    git checkout --ours backend\data\studio.sqlite3     (giữ bản trên máy mình)
    git add backend\data\studio.sqlite3
    git commit

Sau khi kéo database về, đăng nhập bằng mật khẩu đã đặt ở máy kia (không dùng initial-accounts.txt nữa).
